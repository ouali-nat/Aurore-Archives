Protégez votre espace personnel


Créez un code d’accès personnel pour ouvrir votre espace Aurore. Vous pourrez le modifier à tout moment depuis votre profil.












Utilisez 4 à 8 chiffres. Ce code est un verrou d’accès à l’espace sur cet appareil, distinct du mot de passe de votre compte.








Installer Aurore sur cet appareil
Ajoutez Aurore à votre écran d’accueil pour l’ouvrir comme une application, sans l’interface habituelle du navigateur.









Effacer l’historique des téléchargements ?
